# Kayden, the desktop pet (Sidekick)

A chubby, deadpan cat who lives on your Windows desktop, talks with a local AI, plays games through your webcam and remembers you. Everything runs on your own PC.

## Install

1. Download **Sidekick-Setup-x.y.z.exe** from the [latest release](https://github.com/nannigath/sidekick-releases/releases/latest).
2. Run it. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**.
3. A setup window does the rest by itself (Python, Ollama, the AI model and the voice). It downloads several GB, so give it a while.

After that Kayden updates himself: new versions download in the background and install the next time he restarts.

Needs Windows 10 or 11. A webcam and a microphone are optional. The realistic voice needs an NVIDIA graphics card.

This repository only holds the installers. The source code is private.
